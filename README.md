**FocusFlow** is a minimalist native Android application designed to strengthen visual memory, working memory, and selective attention through a structured **10-minute daily cognitive training session**. 

> Selected for inclusion in the **Computer Science Department Quality Assurance Booklet** at Misr Higher Institute for Commerce and Computers (METMANS).

---

## Core Cognitive Modules

Each session dynamically randomizes three complementary brain-training exercises to prevent pattern memorization and ensure continuous mental engagement:

1. **Card Match (Spatial & Visual Memory):** A 3x4 grid of 12 cards testing short-term spatial recall and symbol matching speed (+1 for match, -1 for mismatch).
2. **Color Recall (Selective Attention / Stroop Effect):** Displays a color word printed in a conflicting ink color for 2 seconds, challenging the user to overcome cognitive interference.
3. **Pattern Echo (Working Memory):** A 4-tile sequence generator requiring the user to observe and accurately reproduce visual sequences.

---

## Smart Scoring & Evaluation Engine (Out of 100)

At the end of the 10-minute session, FocusFlow aggregates scores across all three modules (**Card Match: 34 pts**, **Color Recall: 33 pts**, **Pattern Echo: 33 pts**) and classifies cognitive performance:
* **90 – 100 Points:** Peak Focus
* **70 – 89 Points:** Very Good Focus
* **50 – 69 Points:** Moderate Focus
* **Below 50 Points:** Needs Practice
